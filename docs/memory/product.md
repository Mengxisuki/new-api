## 免费账号挂靠与统一资源优先级（本地实现）

用户已批准统一 Key 方案，首期仅 ChatGPT/Codex，挂靠是免费附加服务。`/hosting` 支持多账号、逐账号额度/原厂重置机会、浏览器授权、测试、暂停、重授权和解绑；每个 API Key 独立保存完整顺序，例如 A Key 账号 → 包月、B Key 包月 → 钱包；挂靠页不再管理全局优先级。`/keys` 创建/更新抽屉在分组上方提供“按量计费 → 订阅额度 → 自有账号”默认顺序，支持拖拽、键盘调整与来源启停；每个 Key 独立保存，菜单保留客户端配置。新建默认三类来源，旧 Key 普通改名不扩授权；旧逐账号顺序也不自动折叠为全账号池。订阅页已移除全局计费偏好入口，历史值仅用于无独立策略的旧 Key。旧全局行启动时原样迁移到该用户现存无策略 Key，之后删除，不影响显式策略或未来新 Key。外部充值卡密是独立业务，本轮没有实现。

`controller/resource_relay.go` 在平台分发之前执行来源选择。免费调用不进平台计费链；付费请求冻结包月或钱包，使用同步预留/结算/退款。新鲜明确耗尽可在发送前跳过；上游429、超时或结果未知不能跨来源重放，不自动耗重置机会。`BatchUpdateEnabled` 不会让新策略的退款提前返回成功。未配置策略的旧Key保留原合同。

账号接入采用备注→生成链接→浏览器授权→输入完整回调或 Code→底部完成授权并添加，自动延续保存动作，并从本人账号模型目录选择首个模型执行一次真实测试，通过后才以 active 状态进入调度池。失败、结果未知或没有模型时保留账号供排查，但不参与调度；已有账号重测也先撤销历史验证。测试可能少量消耗原厂额度，不自动重试或使用重置机会。账号归属由New API和gpt-load同时校验，私有执行组不向空过滤/他人Key开放。敏感操作使用会话绑定的单次证明，内部Key以显式持久CRYPTO_SECRET加密；重置UUID及未知结果持久化，后台只恢复创建与删除。自有账号只支持同步 Chat/Responses/compact；其他原有平台接口（图片、音频、Claude/Gemini、实时会话、任务等）跳过不适用的自有账号并按当前 Key 的平台来源授权执行。免费模型亦遵守授权，收费会话预扣后冻结来源。平台客户端导出按真实协议目录可用，挂靠仍要求实测。文件导入及 Claude 自有账号不在首期。

用户否定共享 gpt-load 管理凭据；新链路由 New API 为确切请求签发 30 秒专用断言，gpt-load 向固定回环 New API 核验，实时检查用户启用与请求绑定。长期签名密钥只留 New API，普通管理 Key 和登录 JWT 在 gpt-load 本地拒绝。核验只读可重复，写入继续 UUID 幂等。线上旧实现缺配置问题没有通过补管理 Key 处理，本轮新版未部署。

## 平台事件推送（本地实现）

用户批准以 SSE + HTTP ACK 接入后台及外部客户端，无需 MQ SDK。超级管理员在「系统设置 → 运维 → 事件推送」管理消费者、多个限权 Token、关注主题/用户、投递记录和补发。钱包充值到账、最终费用异常、代充值资料提交生成安全摘要；资料凭据不进入事件。

消费者独立广播，同消费者多个 Token 共享确认进度。默认暂停网络投递，后台继续持久捕获、检测和保留七天；超期未确认计数会提示业务对账。异常检测使用同用户/计费模型/资金来源近期中位数，未完成任务不按估价告警。事件与业务事务同库，最终费用观察与差额资金同事务；缓存确认未知及终态任务未完成结算保留可见标记，模型 Key 两阶段更新失败仍以原错误日志定位。

客户端接入协议、格式与字段、额度单位、错误及重连规则见可独立交付的[事件推送接口文档](../event-hub-api.md)；实现导航、运行与恢复边界见[中文说明](../../README.zh_CN.md#oak-事件推送sse)。SQLite 3.50.4、MySQL 8.4.2、PostgreSQL 14.17 核心与账务矩阵通过，隔离编译实例的管理操作及 SSE/ACK 通过；当前未部署或进行真实付款。
